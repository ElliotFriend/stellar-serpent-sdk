**Goal:** Make spec §11's M1 scope sentence true for the word "unions/enums"
(S1) — a `@contractunion` tagged union and a `@contractenum` int enum that an
author declares strict-clean, constructs, stores, returns, passes, and reads
back, at tier 1 and as WASM, with matching `contractspecv0` entries — plus the
three ruled riders M1-E fed forward (the `topic`-marker refusal, the SPT3019
length-arm drop, the `get` overloads).

**Architecture:** Ruling E1: descriptor-typed factories (`Empty = variant()`,
`Circle = variant(U32)`, `Red = enumvalue(0)`) over two exported base classes,
because a decorator cannot add a member mypy can see (Q2/D9) and an
`Any`-returning factory dies on `--warn-return-any` (§C.8). Ruling E9: a union
instance holds an immutable `Vec` and is **NOT a dataclass** — a dataclass
would silently satisfy the `Struct` Protocol and be classified as a `Map`
(wrong family, wrong storage key, wrong ABI tag, no error, §C.7/F.1.2). Rulings
E3/E4: exactly **one** new IR node (`MakeUnion`, a `MakeTopics` twin dispatched
to the existing `_lower_make_vec`, §C.5 probe A) and two new `Ty` tags with one
derived-set ABI row each; int enums ride `Const`'s U32 path through **two**
tag dispatches (review M1 — not one, as v1 claimed). Ruling E7: entries slot in
the XDR's own kind order, which is byte-safe because the on-chain anchor
declares neither kind (§B.3, and review m4 corrects which anchor that is).

    snippet and not the repo; `cwd=_REPO_ROOT` is what makes `import serpent`

    -- so callers batch their snippets into as few files as the assertions

    result = subprocess.run(
        [sys.executable, "-m", "mypy", "--strict", "--no-incremental",
         "--hide-error-context", "--no-color-output", str(snippet)],
        cwd=_REPO_ROOT, capture_output=True, text=True, check=False,
    )
    return _parse(result.stdout)
